# 定制主题、来源与更新计划

第一版为**一套主题配置生成一份日报**。可以更换关注方向，也可以把几个相关方向写进同一份兴趣描述；界面没有独立的多主题配置切换或分别生成多份日报的功能。

## 换主题时，同时改兴趣与来源

“你的兴趣”决定 Codex 如何在候选中取舍；“资讯来源”决定候选里实际有什么。两项需要一起调整：只改兴趣不会自动找到新主题的新闻，只改来源则可能仍按原来的 AI 与效率工具偏好进行筛选。

### 在界面中设置

1. 展开小窗，点击底部的设置图标。
2. 在“你的兴趣”写明关注主题、实际用途和希望看到的材料类型。内容不能为空，最多 1,500 字。
3. 在“资讯来源”关闭不相关的预置源，并添加相关发布方提供的公开 HTTPS RSS/Atom 地址。至少保留一个启用来源。
4. 点击“保存设置”。配置从下次生成起生效。
5. 回到小窗点击顶部的刷新图标“立即更新资讯”，查看新一期及“资讯源状态”，再根据结果调整。

正在更新时不能保存设置，需要先完成或取消本次更新。更改配置不会自动重写已有日报，也不会删除已保存的历史；生成器仍可能参考最近最多 30 期记录。

### 示例：科技与科学

可以把兴趣改为：

> 关注科技与科学的新进展，优先介绍公开研究、工程工具和可复现的实验。用简短中文说明发生了什么、已有证据和应用条件。区分原始发布事实与 AI 的归纳；证据不足时明确说明。相同事件避免重复介绍。

然后调整来源：

- 添加你选定的研究机构、科研出版方或项目维护者提供的公开订阅地址。
- 关闭与新主题无关的默认源；例如默认 GitHub 搜索仍限定为 `artificial-intelligence` 主题，不会跟随兴趣文字自动改写查询。
- 为重点事件保留不同发布方的来源，以便在浏览器对照原始材料及日期。

这里的文字是筛选偏好示例，不会改变资讯源，也不会启用额外搜索。兴趣字段不能覆盖应用关于来源、工具权限和输出格式的规则。

其他主题，包括政治或金融资讯，也使用相同的“兴趣＋公开来源”配置方式。软件提供有链接的信息整理；本指南不提供这些领域的观点、决策建议或预置立场。来源陈述与 AI 归纳需要区分，重要事实应回到原始材料核验。

## 更新计划

在设置中可以修改：

| 设置 | 当前行为 |
| --- | --- |
| 自动更新开关 | 控制是否每天自动生成一期；关闭后可手动更新 |
| 小时、分钟 | 默认 08:00 |
| 时区 | 默认 `Asia/Shanghai`，即北京时间；可用“北京时间”“Mac 当前时区”“UTC”按钮填入 |
| 本机 Codex 路径 | 留空自动检测；也可指定已安装的 Codex 可执行文件路径 |

默认更新时间按北京时间计算，不随 Mac 的系统时区变化。应用需要运行才能检查计划；暂时断网、休眠或错过时间时，保留已有日报，符合更新条件后补更。修改计划或主题后，如需立刻验证，可手动更新。

## 阅读和核验

小窗适合扫读标题与简短说明。点击标题用默认浏览器打开来源；每个条目的复制按钮可以复制进一步研究的指令，再由你粘贴到 Codex。

不同来源可能报道同一事件。可以据此在浏览器比较原文、发布时间和事实依据，但首版没有自动事实核验或同一卡片的多来源引用界面。“持续关注”也需要变化证据，不会仅凭星数较高就断言项目影响扩大。

## 当前能力范围

- **来源获取**：读取已配置的 RSS/Atom 和预置 GitHub 查询。不会根据主题自动发现订阅、进行新闻全网搜索或补充付费数据库。
- **日报生成**：使用本机已安装、已登录的 Codex；公开候选内容、兴趣和本应用近期日报记录会作为生成输入。没有 API Key 输入界面或独立 API 模式。
- **运行位置**：桌面应用负责定时、采集与保存；本项目没有云端服务器，也没有电脑关机后继续执行的服务。
- **主题管理**：保存一套当前配置、生成一份日报；没有多配置档案界面。
- **来源权限**：使用公开、无需凭据的 HTTPS 地址。没有订阅源登录或私有知识库接入。

更多关于候选配额、日期及失败处理的细节见[资讯来源与筛选规则](SOURCES.md)。

## 在源码中调整默认配置

面向代码维护者，主要入口如下：

| 想调整的内容 | 入口 |
| --- | --- |
| 默认兴趣、北京时间 08:00、默认来源列表 | [Models.swift 中的 AppSettings](../Sources/BriefCore/Models.swift) |
| 来源类型与初始启用状态 | 同文件的 `FeedSource`、`SourceKind`、`AppSettings.defaultSources` |
| 抓取上限、每源配额、GitHub 活跃过滤 | [FeedService.swift](../Sources/BriefCore/FeedService.swift) |
| 每日分区、归纳要求与历史比较规则 | [CodexService.swift](../Sources/BriefCore/CodexService.swift) |
| 设置项与添加来源界面 | [BriefViews.swift](../Sources/SideBrief/BriefViews.swift) |
| 配置校验与本地保存 | [Storage.swift](../Sources/BriefCore/Storage.swift) |

增加默认 RSS/Atom 源时，在 `AppSettings.defaultSources` 中加入 `FeedSource`，提供唯一 `id`、名称和公开 HTTPS 订阅 URL，类型使用默认 `.feed`。专用 GitHub 查询使用 `.github`，其返回值必须符合当前仓库搜索解析器；任意其他 JSON 接口需要另写适配器，单改地址不够。

修改 `AppSettings` 的默认值主要影响新配置。已有安装保存的设置不会因为改了源码默认值就自动替换；现有用户应在设置界面调整兴趣和来源，再重新生成。新主题也需要同步检查来源和生成偏好，不能只替换应用标题。
